┌─ THE PROBLEM ────────────────────────────────────────────────────────────────┐
│                                                                              │
│  CSD-BG Website displays Free Float links in JavaScript-paginated list:     │
│  • 102 pages of data                                                        │
│  • 10 links per page                                                        │
│  • JavaScript-based pagination (not URL parameters)                         │
│  • AJAX-based page loading                                                  │
│                                                                              │
│  Original scraper: ONLY gets first page (10 links)                          │
│  What we needed: ALL pages (~1,000 links)                                   │
└─────────────────────────────────────────────────────────────────────────────┘

┌─ OUR SOLUTION ────────────────────────────────────────────────────────────────┐
│                                                                              │
│  Use Selenium WebDriver to automate browser interactions:                   │
│  1. Open headless Chrome                                                    │
│  2. Navigate to CSD-BG website                                              │
│  3. Detect pagination (102 pages)                                           │
│  4. Loop through all pages:                                                 │
│     - Get page HTML                                                         │
│     - Extract links                                                         │
│     - Click next button                                                     │
│     - Wait for page load                                                    │
│  5. Combine all results (~1,000 links)                                      │
│  6. Store in database and CSV                                               │
└─────────────────────────────────────────────────────────────────────────────┘
