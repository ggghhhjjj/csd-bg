Промяна в акционерите

Този блок показва кои емитенти са с най-голяма нетна промяна в броя акционери между две дати в избрания период.

Сортиране и обхват

  • Бутонът за сортиране превключва между низходящ и възходящ ред.
  • „Топ 5“ / „Покажи всички“ ограничава или разширява списъка.
  • Бутонът за филтър на промяната превключва между всички промени, само увеличения, само намаления и емитенти без промяна; „Топ 5“ важи за активния филтър.

При „Всички промени“ редът „Нетна промяна…“ е сумата по емитенти и съвпада с нетната пазарна промяна за интервала. При филтър (само увеличения/намаления/без промяна) показва се сумата на филтрираните емитенти и отделно нетната пазарна промяна.
